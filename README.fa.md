# آزمایشگاه مجازی عددهای اول — فصل دوم ریاضی پایه هشتم

یک محیط آموزشی تعاملی، فارسی و راست‌چین برای یادگیری اعداد اول و مرکب، غربال اراتستن، تجزیه به عوامل اول و ارزشیابی تکوینی.

## پیش‌نیازها

- نصب **Node.js نسخه ۱۸ یا بالاتر** از نشانی <https://nodejs.org>
- نصب **npm** (همراه Node.js نصب می‌شود)

برای اطمینان از نصب، در خط فرمان (Command Prompt یا PowerShell) دستور زیر را بزنید:

```
node -v
npm -v
```

## مراحل نصب و اجرا روی ویندوز

۱. فایل ZIP را از حالت فشرده خارج کنید (کلیک راست → Extract All).

۲. در پوشه خارج‌شده، نوار آدرس File Explorer را کلیک کنید، `cmd` بنویسید و Enter بزنید تا Command Prompt در همان مسیر باز شود.

۳. وابستگی‌ها را نصب کنید:

```
npm install
```

۴. پروژه را اجرا کنید:

```
npm run dev
```

۵. مرورگر را باز کنید و به نشانی زیر بروید:

```
http://localhost:5173
```

## ساخت نسخه نهایی (Production Build)

برای تولید فایل‌های نهایی در پوشه `dist`:

```
npm run build
```

برای پیش‌نمایش نسخه نهایی:

```
npm run preview
```

## بخش‌های آزمایشگاه

| بخش | توضیح |
|------|--------|
| صفحه اصلی | معرفی آزمایشگاه و مسیر یادگیری |
| غربال اراتستن | حذف تعاملی مضرب‌های ۱ تا ۱۰۰ |
| اول یا مرکب؟ | بازی تشخیص اعداد اول و مرکب |
| تجزیه به عوامل اول | بازی تجزیه با بررسی خودکار |
| چالش پایانی | ۸ پرسش ترکیبی ارزشیابی |
| پیشرفت من | امتیاز، نشان‌ها و عملکرد |
| راهنمای معلم | راهنمای استفاده در کلاس |

امتیازها در مرورگر ذخیره می‌شوند و نیازی به ورود یا پایگاه داده نیست.
